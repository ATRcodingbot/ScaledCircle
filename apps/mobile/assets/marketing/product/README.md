# Public product showcase references

Place reviewed, sanitized ScaledCircle product screenshots in this directory.

- Remove private customer, Business, Scaler, campaign, and financial information.
- Preserve the real product state and terminology shown.
- Do not add fabricated results, routes, provider connections, or marketplace activity.
- Prefer reusable read-only product widgets when they can represent the current UI accurately.

The current funnels use component-driven previews because no sanitized product screenshots were supplied with this release candidate.
